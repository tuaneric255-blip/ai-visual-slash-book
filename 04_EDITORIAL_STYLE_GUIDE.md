# EDITORIAL STYLE GUIDE

## Voice
Practical, visual, evidence-led, teachable.

## Never claim
Semantic slashes are secret/native commands without documentation; exact reliability without recorded tests; universal psychological meaning; physical optical simulation without evidence; 100% identity consistency.

## Standard entry
1 Slash
2 Visual Example
3 Quick Meaning
4 AI Interpretation
5 Prompt Foundation
6 Visual Mechanics
7 What Changes / What Stays
8 Best For
9 When to Use
10 Visual Message
11 Mood / Perception
12 Combine With
13 Avoid / Conflict
14 Pro Prompt
15 Variations
16 Test Status + Note

## Visual standard
A/B uses same benchmark and locks unrelated variables as far as possible.
Show control + representative success + useful failure.
Full-body = head through shoes.
City wardrobe = contemporary and context-appropriate, not automatic stereotype.
Separate technical diagrams from aesthetic examples.
Public comparison cards display the slash label.

## Evidence writing pattern
Definition → mechanism → observable result → communication use → context caveat → combinations → evidence.

## Counting
Only canonical deduplicated records count. Candidate count and verified count are never conflated.
