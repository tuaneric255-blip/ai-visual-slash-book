# MANUSCRIPT STYLE & LAYOUT SPEC

## Page
Target print master: A4 portrait.
Margins: Inside 22 mm; Outside 18 mm; Top 18 mm; Bottom 20 mm.
Body alignment: justified. Avoid rivers with manual line breaks; enable sensible paragraph spacing.
Body font target: Aptos/Arial-compatible sans or publishing font selected at final design stage.
Body: 10.5–11 pt; line spacing 1.15–1.25.
Paragraph: first-line indent 0 or 5 mm depending on final style; use one convention consistently.

## Hierarchy
Book title: 28–34 pt.
Part: 22–26 pt.
Chapter: 18–22 pt.
H2: 14–16 pt.
H3: 11.5–13 pt.
Body: 10.5–11 pt.
Caption/metadata: 8.5–9 pt.

## Header
Left/even page: book short title — AI VISUAL SLASH LANGUAGE.
Right/odd page: current Part / Chapter.
Front matter may suppress running header.

## Footer
Page number on outside edge.
Optional inner footer: evidence legend or section label only where useful.
Do not overcrowd.

## TOC
Automatic Word TOC using Heading 1–3.
Include Parts and Chapters; include H2 selectively in final print TOC.
Create separate Slash Index and Visual Intent Index at end.

## Figures
Every evidence figure gets:
Figure number + slash + benchmark + status.
Caption distinguishes EVIDENCE from ILLUSTRATION.
Never place synthetic run metrics in captions.

## Callouts
Use consistent styles:
- PRINCIPLE
- TEST NOTE
- PRO TIP
- WARNING
- VISUAL INTENT
- EVIDENCE

## Tables
Repeat header row across pages.
Avoid vertical text.
Keep evidence/status columns narrow and readable.

## Page-break rules
Part begins on new page.
Chapter begins on new page.
Keep headings with next paragraph.
Avoid orphan/widow lines where renderer supports it.
Do not split figure caption from figure.

## Production
Source manuscript in structured Markdown + generated DOCX.
Final DOCX must be rendered to PNG and visually inspected page-by-page before release.
PDF derives from the approved DOCX master.
