# TESTING WORKFLOW

Candidate → canonicalization → professional definition → benchmark selection → control → isolated runs → evidence logging → compatibility → production test → human review → status → book entry.

## Hard gates
- No benchmark: no mass test.
- No control: no isolation claim.
- No saved evidence: no VERIFIED.
- No human review: no VERIFIED.
- No evidence-backed entry: no automatic manuscript publication.

## Recommended first calibration
Start with /lowangle because the intended camera-variable change is visually legible. Then /softlight, /leadinglines, /contrapposto and /explodedview. These five expose different evaluation problems before scaling to all 50.
