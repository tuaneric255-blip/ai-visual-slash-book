# CRITICAL TEST CORRECTION — Synthetic Illustration ≠ Evidence

## Why this exists
A composite infographic was generated to visualize the proposed testing framework. It contained invented run counts/status labels and inconsistent example labels. That image is **NOT test evidence** and must never be used to update the slash database.

## Errors caught
- Synthetic “7/10”, “8/10”, “5/10” style counts were not produced by recorded runs.
- VERIFIED/CONTEXTUAL labels were visually invented.
- One contrapposto panel contained a leading-lines label mismatch.
- An illustration can depict what a test *might* look like, but cannot prove model behavior.

## Permanent rule
**Generated explanatory graphics are documentation assets only. They cannot be evidence for the behavior they depict.**

Evidence requires:
1. exact prompt recorded;
2. actual platform/model recorded when available;
3. actual output asset saved;
4. run number recorded;
5. human inspection;
6. status assigned only after review.

This correction strengthens the prime directive: **NO TEST = NO CLAIM.**
