# BOOK EVIDENCE BADGES

Reader-facing evidence labels:

- **TESTED — VERIFIED**: controlled project tests support the stated behavior.
- **TESTED — CONTEXTUAL**: behavior observed but materially context/model dependent.
- **TESTED — UNSTABLE**: behavior appears but lacks adequate repeatability/control.
- **TESTED — REJECTED**: candidate did not support the proposed claim.
- **NOT YET TESTED**: candidate exists but no completed evidence protocol.
- **AUTHOR MACRO**: explicitly defined project shorthand, not a native command.
- **ILLUSTRATION**: explanatory visual only; not behavioral evidence.

Every dictionary entry must display one evidence badge.
