# CODEX EXECUTION PLAN

## Goal
Build an evidence pipeline, not a one-shot AI manuscript.

## Phase 0 — Foundation
Specs, taxonomy, schema, protocol, editorial guide, data templates, benchmark manifest, test queue, manuscript/build structure.

## Phase 1 — Candidate inventory
Normalize, alias, deduplicate, classify semantic/composite/macro. All candidates start UNTESTED.

## Phase 2 — Pilot Lab 50
Pose: /contrapposto /powerpose /hipshift /onehandpocket /armscrossed /forwardlean /walk /lookbackpose /chairsit /dynamicpose
Camera: /eyelevel /lowangle /highangle /topdown /wormseyeview /dutchangle /frontview /sideview /threequarterview /overtheshoulder
Composition: /ruleofthirds /centercomposition /symmetry /asymmetry /leadinglines /diagonalcomposition /scurve /framewithinframe /negativespace /foregroundinterest
Lighting: /softlight /hardlight /windowlight /sidelight /backlight /rimlight /rembrandt /butterflylight /splitlight /lowkey
Product: /centerproduct /floatingproduct /layflat /heroangle /explodedview /watersplash /condensation /productinhand /purewhite /bundlepack

These are CANDIDATES, not verified claims.

## Phase 3 — Calibrate
Record real runs; review successes/failures; establish thresholds; revise to Protocol v1.1.

## Phase 4 — Scale
50 → 500 → 1,000 → remaining candidates. Never publish UNTESTED as verified.

## Phase 5 — Manuscript
Only APPROVED evidence-backed records auto-generate dictionary entries. CONTEXTUAL carries limitations. REJECTED goes to Failed Slash Lab.

## Phase 6 — Recipes
300–500 recipes from compatible tested controls.

## Phase 7 — Visual production
A/B cards; control/test/failure; diagrams; city packs; product boards; video examples; indexes.

## Phase 8 — QA
Automated: duplicates, missing status, claims without evidence, fake metrics, broken assets, alias conflicts, macro misclassification, terminology.
Human: visual theory accuracy, image quality, identity/product consistency, pedagogy, source/copyright review.

## Definition of Done
Canonicalized + concept defined + tests complete + evidence saved + human reviewed + status assigned + copy generated from evidence + visuals linked + QA passed.
