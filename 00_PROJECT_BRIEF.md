# AI VISUAL SLASH LANGUAGE — PROJECT BRIEF

## Mission
Build a practical, evidence-led Visual Slash Dictionary & Prompt Engineering Handbook for AI image and video generation.

**Pipeline:** Visual Intent → Visual Language → Slash → AI Interpretation → Prompt Foundation → Visual Result → Combination → Pro Control.

## Prime directive
**NO TEST = NO CLAIM.**

No slash may be described as reliable merely because the wording sounds plausible. Production entries require controlled tests and human review.

## Scope
- Start with ~3,000 candidate slashes before deduplication/testing.
- Final count is evidence-driven, never predetermined.
- ~150–180 chapters across visual theory, people, pose, composition, camera, lighting, color, scene/city, product, food, advertising, design, editing/reference control and video.
- 300–500 tested production recipes.
- Control/Test/Failure evidence where appropriate.
- Failed Slash Lab for useful failures.

## Terminology
- **Semantic Slash:** self-descriptive shorthand, e.g. /lowangle.
- **Composite Semantic Slash:** understandable but potentially variable, e.g. /seoulstreetlook.
- **Defined Slash / Macro:** project-defined shorthand requiring explicit mapping, e.g. /storyvideo.
- Never call these native/secret platform commands without official documentation.

## Reader levels
1. SIMPLE — copy and see the effect.
2. UNDERSTAND — learn the visual mechanism and intent.
3. PRO — expand to full prompts, combine controls, debug conflicts and build macros.

## Evidence states
UNTESTED · VERIFIED · CONTEXTUAL · UNSTABLE · REJECTED

## Deliverables
Canonical slash database; test corpus; benchmark suite; manuscript; recipe library; indexes; compatibility matrix; reproducible build/export pipeline.
