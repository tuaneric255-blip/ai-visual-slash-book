# TESTING PROTOCOL v1.0

## Prime directive
**NO TEST = NO CLAIM.**

## Evidence states
UNTESTED; VERIFIED; CONTEXTUAL; UNSTABLE; REJECTED.

## L1 — Isolation
Neutral control vs identical prompt + exactly one candidate slash.

## L2 — Compatibility
Combine candidate with a small number of orthogonal controls. Test likely conflicts separately.

## L3 — Production
Use in a realistic recipe. Production beauty is not isolation evidence.

## Benchmark suite
People: adult female, adult male, couple, group.
Product: perfume, skincare, beverage, electronics, fashion item.
Other: food, interior, architecture.

## Procedure
1. Define the professional concept before generation.
2. State expected visible mechanism.
3. Select benchmark(s).
4. Generate control.
5. Generate isolated test.
6. Repeat and record actual trials.
7. Inspect unintended changes.
8. Run relevant compatibility tests.
9. Save representative success and failure.
10. Human review assigns evidence state and notes.

## Evaluation
Semantic alignment; visual distinctness; repeatability; specificity; side effects; cross-context robustness; production usefulness.

## Specialist checks
Pose = body mechanics/anatomy.
Composition = visible spatial organization.
Lighting = direction/softness/contrast/shadow pattern.
Lens = aesthetic/perspective cue unless optical fidelity is demonstrated.
Product = geometry/label/material stability.
Identity = evaluated separately from style quality.
Video = temporal continuity, motion intent, artifacts.

## Anti-bias
Never beautify isolation prompts with unrelated modifiers.
Never cherry-pick only best results.
Generating model cannot be sole verifier.
Semantic plausibility is not evidence.
Keep failed outputs.
Never fabricate metrics.

## Pilot
50 candidates: 10 Pose + 10 Camera + 10 Composition + 10 Lighting + 10 Product.
Pilot calibrates thresholds, run counts, benchmark quality, naming/storage and Protocol v1.1.
