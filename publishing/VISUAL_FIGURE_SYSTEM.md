# VISUAL FIGURE SYSTEM

## Figure families

### F01 — Control / Result Pair
Hai khung ảnh cùng kích thước. Control trái, Result phải. Slash label nằm trực tiếp dưới Result. Caption nằm dưới toàn figure.

### F02 — Slash Anatomy
Một ảnh final + slash stack + callout/legend cho từng layer: body, pose, camera, framing, light...

### F03 — Process Flow
Node + connector. Dùng cho quy trình có thứ tự.

### F04 — Layer Stack
Các lớp xếp dọc/ngang, dùng cho grammar và architecture.

### F05 — Conflict Matrix
Bảng/ma trận: compatible, soft conflict, hard conflict, contextual.

### F06 — A/B/C Variation
Một control và nhiều variation; chỉ dùng khi provenance từng output rõ ràng.

### F07 — Reference / Edit
Reference → requested change → applied result; kèm Keep/Change box.

### F08 — Video Shot Flow
Start Frame → Subject Action → Camera Motion → End Frame; có continuity lock ở một lane riêng.

## Caption convention
**Figure [chapter].[number] — [Tên figure].**
Dòng thứ hai nếu cần: Test Evidence / Documentation Illustration / Reference Example.

## Slash label convention
Slash luôn đặt dưới ảnh, không chèn đè lên khuôn mặt/sản phẩm trừ khi bản thân figure cần annotation.
Font monospace; slash là phần nổi bật nhất sau hình.

## Image priority
Ở Dictionary/Field Guide pages, hình ảnh chiếm khoảng 55–70% vùng nội dung nếu entry phụ thuộc trực quan.
