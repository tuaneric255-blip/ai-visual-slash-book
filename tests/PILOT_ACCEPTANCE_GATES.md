# PILOT ACCEPTANCE GATES

## Gate A — Benchmark ready
Reference exists + baseline prompt + locks + human approval.

## Gate B — Isolation ready
Control/test prompts are non-conflicting and differ only by the tested semantic variable as far as practical.

## Gate C — Evidence complete
All actual runs saved and registered. Failures retained. No invented metrics.

## Gate D — Human reviewed
Reviewer inspects the intended professional mechanism, side effects and repeatability.

## Gate E — Status
Only after A–D may status leave UNTESTED.

## Gate F — Book entry
Only reviewed evidence-backed claims may enter the main dictionary. Limitations travel with the entry.

## Gate G — Visual card
Comparison cards must use real registered evidence assets. Synthetic explanatory cards must be visibly marked “ILLUSTRATION / NOT TEST EVIDENCE”.
